# 리더의 자리 · 리더십 시뮬레이션 샘플

암호화폐 자산운용사의 팀장이 되어 시장 급변, 팀 간 갈등, 사람 문제 앞에서 결정을 내리는 교육용 시뮬레이션 게임 샘플입니다.

**▶ 바로 플레이하기: https://soyoungjung483-spec.github.io/leadership-demo/**
(PC와 모바일 브라우저 모두 가능, 한 판에 5–10분)

> 공개된 자료만으로 만든 비공식 샘플입니다. 시나리오와 수치는 모두 가상이며, 실존 인물 대신 역할로 표기했습니다.

---

## 왜 만들었나

리더십 교육은 강의로 듣는 것보다 직접 결정해 보고, 그 이유를 이야기할 때 더 오래 남습니다. 이 샘플은 실제 조직의 맥락(팀·셀 구조, 업무 특성, 과거 시행착오)을 반영한 상황에서 리더가 결정을 내리고, 그 결정을 회고 대화로 이어 가도록 설계했습니다.

## 플레이 방식

1. **역할 선택:** DeFi 팀장, 자산운용 팀장, 테크 팀장 중 하나를 고릅니다.
2. **상황 6개:** 팀별 상황 5개와 크로스팀 위기 1개(‘블랙 먼데이’)를 차례로 마주합니다.
3. **결정과 결과:** 선택에 따라 지표 5개(수익, 안정성, 팀 신뢰, 협업, 실행 속도)가 바뀝니다. 일부 결정은 몇 라운드 뒤에 결과가 돌아옵니다.
4. **리더십 리포트:** 선택에 드러난 7개 역량(결단, 위기, 소통, 코칭, 위임, 조율, 원칙)을 바탕으로 리더십 스타일, 성장 포인트, 회고 질문을 보여 줍니다.

## 설계 원칙

- **정답 없는 딜레마:** 모든 선택은 무언가를 얻고 무언가를 잃습니다. 뻔한 정답이 보이면 학습이 일어나지 않습니다.
- **지연되는 결과:** 단기 성과와 장기 신뢰 사이의 긴장을 체감하도록, 일부 결정의 결과는 나중에 드러납니다.
- **점수보다 대화:** 상황마다 회고 질문을 두어, 게임을 1on1이나 워크숍의 대화 소재로 쓰도록 했습니다.

## 참고한 자료

- 채용 페이지의 팀 인터뷰 (DeFi팀, 자산운용팀, 테크팀): 팀·셀 구조와 미션
- 전 CTO의 기술 블로그 회고 [「CTO의 시행착오」](https://tech.hyperithm.com/cto-challenges): 기술 의사결정, 위임, 1on1, 보상 기대 관리, 팀 간 협업 사례

## 실제 교육 프로그램으로 발전시킨다면

1. **현장 인터뷰로 시나리오 현실화:** 팀장과 셀 리더를 인터뷰해 실제로 겪은 딜레마로 시나리오를 바꿉니다.
2. **회사 리더십 원칙과 연결:** 역량 태그를 회사의 리더십 원칙과 평가 기준에 맞춰 다시 정의합니다.
3. **크로스팀 동시 플레이 워크숍:** 세 팀장이 함께 플레이하며 공유 자원을 협상하는 반나절 워크숍으로 운영합니다.
4. **평가가 아닌 성장 도구로:** 결과는 점수가 아니라 1on1과 리더 코칭의 대화 소재로 활용합니다.
